    HTML Paragraph

    HTML stands for Hyper Text Markup Language.

    HTML is use to creat and structure webpage.

    Important Points :
    1. The (p) tag defines a paragraph.
    2. It has an opening tag (p) and a closing tag (/p).
    3. Multiple paragraph can be written using multiple (p) tags.
    4. A browser automatically starts a new line for each paragraph.
    5. Paragraph make long text more organized and readable.

        6. In short: the (p) tag is used to creat and display paragraph of text in an HTML web page.

    HTML Lists

    Attributes

    This integer attribute indicate the current ordinal value of the list item as defined by the (ol) element. The only allowed value for this attribute is a number, even if the list is displayed with Roman numerals or letters. List items that follow this one continue numbering from the value set. This attribute has no meaning for unordered list (ul) or for menus (menu).

    This character attribute indicates the numbering type:
    • a:lowercase letters
    • A:uppercase letters
    • i:lowercase Roman numerals
    • I:uppercase Roman numerals
    • 1:numbers

    HTML Media

    Value

    A MediaList object. It's value is set by the media attribute on the corresponding (link) or (style) element. If the media attribute is not set or empty, it returns an empty MediaList, i.e.,a MediaListwith the length property equal to 0

    Although the media property itself is read-only in the sense that you can't replace the MediaList object, you can still assign to its mediaText properly. You can also modify the MediaList object using the appendMedium() and deletMedium().
